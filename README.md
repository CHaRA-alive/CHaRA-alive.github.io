# Cai Jiayi 的个人主页

纯静态个人主页，使用原生 HTML、CSS 和 JavaScript，部署在 GitHub Pages。

## 页面

- `index.html`：首页，包含个人方向、三个重点项目和联系方式。
- `projects.html`：项目分类页，使用可展开的分类文件夹整理项目。
- `style.css`：天空渐变、毛玻璃、响应式布局与日夜主题。
- `script.js`：云和花瓣动画、打字机、日夜主题、滚动出现和回到顶部。

## 项目结构

首页只展示三个重点项目，更多内容从“按分类展开”进入项目分类页。

- 后端与数据库：校园共享单车管理系统。
- 机器学习与数据分析：PyTorch 分类练习。
- 课程与学习资料：明确标注为 fork 的 NLP 课程资料。

## 内容原则

- 项目描述对应仓库中实际存在的代码。
- 原创项目、练习代码和学习资料分开标注。
- 不展示无法核实的会员身份、贡献数量或研究经历。

## 本地预览

直接用浏览器打开 `index.html`，或在当前目录启动任意静态文件服务器。

## 部署

仓库推送到 `main` 后，由 GitHub Pages 自动构建和发布。
